# nvim-desert

A Neovim colorscheme based on the classic desert palette, built from the following Alacritty terminal colors.

## Terminal Behavior

`draw_bold_text_with_bright_colors = true` — Alacritty renders bold text using the bright color variants (8–15) instead of the normal ones (0–7). Bold syntax tokens in the colorscheme therefore effectively use the brighter palette.

## Source Colors (Alacritty)

### Primary

| Role               | Hex       |
|--------------------|-----------|
| background         | `#333333` |
| foreground         | `#fffdb3` |
| bright_foreground  | `#ffffff` |
